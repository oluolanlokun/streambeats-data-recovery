# StreamBeats — Listening Data Recovery

## Project Overview

StreamBeats is a Python group project developed for COSC 311 at Salisbury University.

The project simulates a music streaming service experiencing a server crash, resulting in partially corrupted listening records. The goal was to recover usable data, handle invalid records, and analyze the recovered listening history.

## Technologies Used

- Python
- Object-Oriented Programming
- File I/O
- Exception Handling
- NumPy and pandas

## Project Features

- Models songs, listeners, and listening events using Python classes.
- Processes listening records from a generated dataset.
- Identifies and handles incomplete or corrupted records.
- Recovers valid listening events for further analysis.
- Uses Python data analysis tools to explore recovered information.
